# SDP Analysis Dashboard（統合版）

**SDP (Skill Driven Production)** - 高炉メーカー向けスキル分析ダッシュボード

## 🔀 統合版について（2026-10-23 作成）

このリポジトリは、v2（SDP-Analysis-Dashboard2）を土台に、v1（SDP-Analysis-Dashboard）の固有機能を統合した集約版です。

- v2から: 10ステップ分析フロー、5種類のCSVデータ基盤、ドキュメント群
- v1から統合: 📋 アクションプラン（施策パッケージ＋投資対効果シミュレーション）、📉 継続モニタリング（健全性スコア＋早期警告）、📁 生データ閲覧（フィルタ＋CSVダウンロード）、共通スタイル（utils/styles.py）
- v1画面が前提とするデータ形式への変換は `legacy_adapter.py` が担当します（列名の対応付けと「平均スキル予測値」の補完）
- アクションプランの優先スキルは、対象拠点のボトルネックデータでスキルギャップが最大のカテゴリを自動選択します
- 重複していた `generate_dummy_data_v2.py`（`generate_dummy_data.py` と完全同一）は統合版では削除しました

## 📌 概要

このダッシュボードは、製造業（特に高炉メーカー）のグローバル拠点におけるスキルと生産性の関係を可視化し、データドリブンな人材育成戦略を支援する10ステップ分析プラットフォームです。

## 🎯 10ステップ分析フロー

### STEP 1: 🌍 全社俯瞰
- グローバル拠点の生産性・品質・安全指標を比較
- 世界地図上でのヒートマップ表示
- 3軸レーダーチャート（効率・品質・安全）

### STEP 2: 🏭 拠点内比較
- ライン別・シフト別のパフォーマンス差異分析
- ボックスプロット、ヒートマップ
- 時系列トレンド分析

### STEP 3: 🎯 スキル構造比較
- ライン間の力量分布の違いを可視化
- スキルカテゴリー別レーダーチャート
- 力量レベル（A〜D）分布分析

### STEP 4: 📊 力量と生産性の相関分析
- スキルスコアと生産効率・品質の相関係数計算
- 散布図・回帰分析
- スキルレベル別パフォーマンス比較

### STEP 5: 🔍 工程別スキルボトルネック分析
- スキルギャップ（要求レベル - 現在レベル）の特定
- 工程×スキルカテゴリーのヒートマップ
- 優先順位マトリクス（ギャップ × 影響度）

### STEP 6: 👥 個人・チーム力量の詳細分析
- メンバー別スキルマップ
- 育成ターゲットの特定

### STEP 7: 📚 教育・訓練データとの連携
- 研修プログラム別受講状況
- 教育投資ROI分析

### STEP 8: 📊 改善施策の実行・効果モニタリング
- Before/After比較
- KPIトレンド分析

### STEP 9: 🏆 他拠点とのベンチマーキング
- 優良拠点の成功パターン抽出
- クラスタ分析

### STEP 10: 📊 全社KPIダッシュボード
- Skill Index、Skill Gap改善率
- 経営レベルでの人的スキル管理

## 🚀 セットアップ

### 1. 依存パッケージのインストール

## 💡 使用例

### 1. 全社レベルでの課題拠点特定
STEP 1で各拠点の総合スコアを確認し、乖離の大きい拠点を特定

### 2. 拠点内のボトルネック特定
STEP 2-3でライン・シフト別の差異とスキル構造を分析

### 3. スキル起因の問題検証
STEP 4でスキルと生産性の相関を定量評価

### 4. 具体的な改善施策立案
STEP 5で優先順位の高いスキルギャップを特定し、教育計画を策定

### 5. 効果測定とPDCA
STEP 8-10で改善効果を継続モニタリング

## 📈 KPI指標

- **Skill Index**: 拠点・ライン・個人のスキルレベル
- **生産効率指数**: 日本拠点を100とした相対指数
- **品質指数**: 品質不良率の逆数指標
- **安全指数**: 労災発生率から算出
- **総合スコア**: 3指標の平均値

## 🔧 カスタマイズ

### スキルカテゴリーの変更
`generate_dummy_data.py` の `SKILL_CATEGORIES` を編集

### 影響度の調整
`data_loader_sdp.py` の `get_skill_categories()` で重み付けを変更

### 拠点の追加
`generate_dummy_data.py` の `LOCATIONS` に拠点情報を追加
